# Esports Trading Operations & Sportsbook BI Analysis

## 🎯 Project Overview
This repository contains an end-to-end Business Intelligence and Data Analytics project tailored for **Esports Trading Operations**. The objective of this project is to model, monitor, and optimize trading performance, track core sportsbook KPIs, and translate complex datasets into actionable insights for non-technical stakeholders, such as traders and risk management teams.

The architecture and queries leverage large-scale match datasets, cleaning raw data using **advanced SQL**, and establishing a robust reporting framework.

---

## 📊 Key Performance Indicators (KPIs) Tracked
The analytical framework focuses on the core pillars of esports betting and trading operations:
1. **Turnover:** Total volume of stakes placed across different esports titles (e.g., Counter-Strike, League of Legends) and tournament tiers.
2. **Gross Gaming Revenue (GGR):** The net win/loss for the operator (`Turnover - Payouts`).
3. **Margin (Hold %):** The theoretical and actual profitability built into the odds (`GGR / Turnover`).
4. **Exposure:** Real-time risk tracking indicating maximum potential financial liability on specific match outcomes or betting markets.

## 🛠️ Tech Stack & Skills Demonstrated
* **Advanced SQL:** CTEs, Window Functions, Complex Aggregations, Performance Optimization, and Data Cleaning.
* **Data Visualization (BI):** Designed for implementation in Power BI and Tableau.
* **Python (Nice-to-Have):** Utilized for initial dataset profiling, data pre-processing, and exploratory data analysis.
